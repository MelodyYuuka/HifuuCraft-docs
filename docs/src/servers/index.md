# 服务器总览

云梦都是一个始于 2017 年的 Minecraft 服务器，提供多个版本和不同风格的玩法。

## 玩法一览

| 玩法 | 版本 | 状态 | 入口 |
| --- | --- | --- | --- |
| 1.12.2 生存服 | Minecraft 1.12.2 | 长期运营 | [查看详情](./survival-1.12/) |
| 26.2 空岛服 | Minecraft 26.2（最低支持 1.21.8） | 主要玩法 | [查看详情](./skyblock-26.2/) |
| 1.21 生存服 | Minecraft 1.21 | 测试中 | [查看详情](./survival-1.21/) |
| 小游戏 | 多版本 | 规划中 | — |

目前还拥有彩蛋战争、战桥、起床战争、TNT Run、密室逃脱等小游戏玩法；具体开放情况以服务器内实际菜单为准。

## 更新计划

- 开设 1.21 生存服
- 开设小游戏派对和僵尸末日
- 持续完善空岛附魔系统，增加更多附魔

:::tip 客户端
您可以直接使用原版客户端进入云梦都，不需要安装额外 Mod。优化类模组不会影响正常游玩。
:::

## 主要玩法

### 1.12.2 生存服

![1.12 主城](/images/servers/ymd-1.12-main-city.webp)

这是服务器最早开设的玩法之一，拥有粘液科技等玩法插件，也保留了许多老玩家建筑和遗迹，适合探索与考古。

- [进入 1.12.2 生存服文档](./survival-1.12/)
- [查看 McMMO 技能系统](./survival-1.12/plugins/mcmmo.md)
- [查看粘液科技](./survival-1.12/plugins/slimefun.md)

### 26.2 空岛服

![樱花小院](/images/servers/cherry-blossom-house.webp)

空岛服更加偏向原版，在原版基础上通过插件增加装饰品和原创附魔系统。

- [进入 26.2 空岛服文档](./skyblock-26.2/)
- [查看空岛附魔指南](./skyblock-26.2/enchantment/enchantment-general.md)

### 1.21 生存服

当前仍在测试中，相关页面和玩法可能会持续调整。

- [进入 1.21 生存服文档](./survival-1.21/)

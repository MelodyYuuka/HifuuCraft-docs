# 快速开始

里吼阿，初次见面，请多指教！云梦都是一个 Minecraft 服务器，始于 2017 年。

## 进入服务器前

为了进入服务器，您需要使用游戏版本不低于 1.12.2 的 **Java 版 Minecraft**。可以使用原版客户端，也可以使用 Forge、Fabric 等模组加载器，并安装 Sodium 等不改变玩法的优化模组。

:::info 客户端兼容性
服务器支持多个 Minecraft 版本。不同玩法的推荐版本可能不同，具体请以 [服务器总览](/servers/) 和对应玩法页面为准。
:::

如果您使用手机版 Minecraft，可能需要使用 QQ 群内提供的整合包。

## 进入服务器

启动游戏后，点击 `多人游戏` → `添加服务器`，输入任意一个服务器地址：

:::warning
不要把 IP 地址后的空格和括号一并复制到服务器地址栏。
:::

- `yunmengdu.cn`（主线路）
- `m.yunmengdu.cn:35565`（备用线路）
- `sblt.yunmengdu.cn`（联通专用）

输入服务器地址后点击 `完成`，再点击 `加入服务器` 即可。

## 进入具体玩法

进入大厅后，您需要创建或登录账号。账号对应您的 Minecraft 游戏名。

登录后，可以使用物品栏中的 `传送菜单（指南针）`，或右键大厅内的 NPC，进入对应服务器。

- [1.12.2 生存服](/servers/survival-1.12/)
- [26.2 空岛服](/servers/skyblock-26.2/)
- [1.21 生存服](/servers/survival-1.21/)

## 服务器守则

:::info
如果您认为自己受到了不正确的处罚，或在游戏中遇到了问题，请联系管理员。
:::

- 允许使用 `Xaero's Minimap` 等辅助性模组，但禁止使用外挂。
- 禁止矿石透视（xray）、杀戮光环等第三方作弊功能。
- 文明聊天，不得恶意骚扰或人身攻击其他玩家。
- 不得偷窃其他玩家物品、恶意破坏建筑或锁定其他玩家箱子等，避免破坏他人的游戏体验。

违反规则时，服务器会依据善意推定原则处理。服务器管理员对规则保留最终解释权。

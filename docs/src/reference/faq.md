# 常见问题

## 皮肤与设置不一致

客户端安装的皮肤 Mod 可能会优先从其他皮肤站读取同名玩家的皮肤。请检查皮肤 Mod 的配置，关闭不需要的皮肤站来源，再重新进入服务器。

## 自己看到的是默认皮肤

如果已经设置过皮肤，通常是客户端暂时没有加载成功。可以依次尝试：

1. 使用 `/skin update` 刷新皮肤。
2. 切换一次服务器或世界，等待皮肤重新加载。
3. 使用 `/skin clear` 清除设置后，再通过 `/skin set <正版用户名>` 重新设置。

如果始终无法加载，可能是当前网络无法正常连接 Mojang 的皮肤服务。

## 别人看到的是默认皮肤

通常是对方客户端暂时没有加载成功。可以让对方重新进入服务器，或切换一次服务器、世界后再查看。

## 联通网络延迟或丢包较高

可以尝试使用联通专用线路：`sbdx.yunmengdu.cn`。

如果问题持续存在，请在交流群中提供所用网络运营商、客户端版本和具体报错信息，方便管理员排查。

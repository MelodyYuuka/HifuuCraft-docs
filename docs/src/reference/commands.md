# 常用指令

## 群内指令

### `/playerinfo [玩家名]`

查询玩家数据。可以直接在指令后填写玩家名，也可以 `@` 群成员；使用后者时会返回该成员最后绑定的游戏账号。

### `/online`

查询服务器当前的在线玩家。

### `/msgs <文本>`

向服务器内发送消息。

:::warning
服务器并非法外之地，请文明交流并对自己的发言负责。
:::

### `/checkbind`

查看游戏账号绑定情况。留空时查询自己的账号，也可以 `@` 其他群成员进行查询。

### `/生成云梦都全身照`

生成自己的游戏角色全身照，也可以 `@` 其他群成员。图片依赖该玩家当前的服务器皮肤。

### `/setskin`

设置服务器皮肤。发送指令后，上传一张 **64 × 64、PNG 格式的原始皮肤图片**。

## 服务器内指令

### `/bindqq <QQ 号>`

绑定 QQ 账号，用于账号找回和玩家数据查询。

:::important
建议进入服务器后尽快完成绑定。
:::

### `/bindqq clear [玩家名]`

解除账号绑定。留空时解除最后绑定的玩家账号；更换绑定账号时也可以在指令后指定玩家名。

:::warning
如非必要，请不要解除绑定。
:::

### `/skin set <正版用户名>`

<sup>主条目：[SkinsRestorer](../plugins/skinsrestorer.md)</sup>

将皮肤设置为指定正版用户名对应的皮肤。如果离线账号切换为正版账号后皮肤没有刷新，也可以使用此指令重新设置。

在子服中使用时，可能会暂时断开连接并返回大厅。

### `/skin clear`

清除当前皮肤设置。当 `/skin set` 或 `/skin update` 没有效果时，可以先清除再重新设置。
